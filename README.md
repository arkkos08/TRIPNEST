🌍 Tripnest is a full-stack travel social platform for showing your trips by sharing pictures, planning tips and connecting with other people.

✨ Features

- 🗺️ Interactive world map
- 📊 Percentage of the world explored based on visited countries
- ✈️ Trip planning
- 📸 Travel posts with photos and ratings
- ❤️ Likes, comments and saved posts
- 👥 User profiles and interactivity
- 💬 Private messaging
- 🏨 Flight and hotel integrations
- 🔎 Travel offers

🚀 How to Run

-REQUIRMENTS

1)Node.js

2)Npm

3)Web browser

-STEPS 

1)Make sure Node.js is installed.

2)You can check with: node -v and npm -v (If both commands return a version number, continue.)

3)Navigate to the extracted TripNest folder. (cd TRIPNEST)

4)Install the required dependencies (npm install)

5)Run: node server.js

6)Go to: http://localhost:3000
